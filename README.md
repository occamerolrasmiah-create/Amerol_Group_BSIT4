# Different roles. One common goal.

**We are a team of four students working together to create useful software solutions. Each member has a different responsibility, but we share one goal: to develop a system that can help real users.**

### Who We Are

## Meet the team behind the work

**Our team is composed of a programmer, an analyst, a technical writer, and a project manager. We combine our knowledge and skills to plan, develop, and document our project.**

**We believe that teamwork, communication, and responsibility are important in creating a successful system.**

### Our Purpose

**Our purpose is to use our technical skills to create a system that responds to the needs of our client and makes daily library tasks more organized and manageable.**

### Our Goal

**To develop a reliable and user-friendly Library Management System for the Misamis Oriental Provincial Library.**

## Mobile Applications

## One system, two mobile apps

**Each app is made for a different user of the library.**

### Staff Mobile Application

![Staff Mobile Application screens](https://amerol-group-bsit4.onrender.com/wp-content/uploads/2026/11/staff.jpg)

**For library staff**

**A mobile application that allows library staff to scan book barcodes, manage borrowing and returning transactions, monitor book availability, and record damaged or lost books.**

**Features**
- Barcode scanning
- Borrow & return
- Book availability
- Damaged or lost books

### Borrower Mobile Application

![Borrower Mobile Application screens](https://amerol-group-bsit4.onrender.com/wp-content/uploads/2026/11/borr.jpg)

**For borrowers**

**A mobile application that allows borrowers to browse available books, view book details and locations, manage their profiles, monitor borrowing history, and receive library notifications.**

**Features**
- Browse books
- Book locations
- Profile
- Borrowing history
- Notifications
